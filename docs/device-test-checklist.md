## 本地运行

```bash
npm install
npm run dev
```

手机和电脑连同一个 Wi-Fi，用 `npx vite --host` 启动后，在手机上打开终端里显示的局域网地址。
注意：Service Worker 和部分音频功能要求 HTTPS 或 localhost，离线一项需要部署到 HTTPS 地址后再测。
